# ci/contracts/errmsg/comment.txt —— R5 错误码契约基准（comment 域）
#
# 【这是什么】
#   Java 侧comment 域错误码契约的**机器可读基准**。
#   CI 用 `ci/scripts/check-errmsg-contract.sh` 跑 **Java 半边探针**
#   （`tools/errmsg-probe/comment/java/Probe.java`）并与本文件的 dump 段**逐字节**比对。
#
# 【权威性来源 = Go 真源（只读 · 冻结）】
#   Go 真源：Sea-RideTheWind_golang/service/comment/common/errmsg/errmsg.go
#     · NewGrpcErr :33-35 · const 块 :37-65 · codeMsg 表 :67-94 · GetErrMsg :97-103
#   Java 被测：service/comment/comment-common/src/main/java/com/rag/comment/comment/common/errmsg/{CommentErrorCode,CommentErrorMessages,CommentCodeError,CommentGrpcError}.java
#
# 【提取方式（离线 · 一次性 · 可复算）】
#   2026-10-31 用 `tools/errmsg-probe/comment/run-parity.sh` 跑**双侧对拍**：
#     · Go 半边：把真源 `errmsg.go` 复制进临时模块、与真源**同包**编译后跑
#       （复制件与真源比 sha256，不一致即 exit 2 ⇒ 验的确实是真源）；
#     · Java 半边：`javac` 编译探针 → 跑**真实编译产物**（`<域>-common` 的
#       `target/classes`）⇒ 探针自己**不持有任何码值/文案常量**（否则是「拿 RAG 的值验 RAG 的值」）。
#   本文件 = **Java 侧 dump**（Java 侧应当满足的契约）。
#   ⇒ Go 仓**不需要**在线、Go 工具链**不需要**进 CI 镜像。
#
# 【裁定依据】
#     · Go↔Java 双侧 dump 有 **3 条差异**，全部落在 `OBS` 段。
#     · 裁定依据：`docs/DRIFT/comment/common.md` §3-D1（业务码 wire 载体差异）+ `docs/DRIFT/comment/vs-common.md`
#     · + `tools/errmsg-probe/comment/README.md` §五（逐条 Go 出处 / RAG 出处）。
#
# 【本域已批准差异清单】（Go 侧 vs Java 侧 · **逐条** · 共 3 条）
