# 原任务迁移对照表（旧 RoundPlan → 新 RoundPlan）

> **本表用途**：把旧 RoundPlan 的**每一个**编号任务逐条对到新计划（形态 A「接着干型」· 7 个正常轮次），保证「旧任务无去向 = 0」。
> **口径说明**：
> - **旧任务 58 条 = 旧编号任务 40 条**（`T-0.1`~`T-0.7` / `T-1.1`~`T-1.7` / `T-2.1`~`T-2.11` / `T-3.1`~`T-3.7` / `T-4.1`~`T-4.8`）**＋ R5 欠账 8 条**（`R5-1`~`R5-8`）**＋ R5 派工单 10 张**（`R5-F1`~`R5-F10`）⇒ **逐条可追溯**。
> - **本轮新发现并纳入新计划的 6 组**（`NEW-P0#5` / `NEW-E65` / `NEW-E66` / `NEW-JUDGE` / `NEW-CLOSE` / `NEW-ACCEPT`）在旧计划中**无此条** ⇒ 单列一节并标注「旧计划无此条」。
> - **新计划 7 个轮次**：Round 1 全服务起栈 / Round 2 E65·E66 出向 deadline / Round 3 基线复判订正 / Round 4 B/C/D 类残留清零 / Round 5 取证与台账对齐 / Round 6 收口回归 / Round 7 阶段一最终验收（执行细节见 `round-01/`~`round-07/`）。
> - **新任务 ID 空间** = `P<轮>-T<序号>`（`P1-T01`…`P7-T01`）⇒ 与旧编号 `T-x.x` / `R5-n` / `R5-Fn` **不冲突**；旧编号原样保留。
> - **「已完成」= 不再需要执行** ⇒ 不声称要重做；标「已完成」的行只在「新任务 ID」列指出其结论被哪条新任务继承。
> - **本表不替代逐轮计划**，也**不下阶段一结论**（结论归 `docs/PhaseGoal-judge.md`）；本表是**计划层产物**，不执行任何整改。
