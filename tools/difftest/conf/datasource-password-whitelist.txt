# 判据：`tools/difftest/check-datasource-password-form.py`
#   ⇒ rpc 模块的运行配置里，`POSTGRES_PASSWORD` **不得**写成 `${POSTGRES_PASSWORD:<默认值>}`
#   ⇒ 必须与 Go 逐字同形 = **裸** `${POSTGRES_PASSWORD}`
#
# 为什么这是「真漂移」而不是「更严的有意偏离」：
#   · Go 真源侧全部 rpc yaml 的口令占位符都是**裸** `${POSTGRES_PASSWORD}`（无默认值）；
#   · go-zero 的配置加载 = `loader([]byte(os.ExpandEnv(string(content))), v)`（core/conf/config.go）
#     ⇒ **`os.ExpandEnv` 不认 `${VAR:default}` 语法**（实测：带默认值写法展开成**空串**）
#     ⇒ 缺变量 ⇒ 空口令 ⇒ 连库失败 ⇒ **Go 侧是 fail-fast**；
#   · RAG 侧用 Spring 的 `:default` 语义 ⇒ 缺变量时会**用那个默认值连上去**
#     ⇒ ⇒ **RAG 比 Go 松** ⇒ ⇒ 是漂移，不是「更严」⇒ ⇒ **不需要为「保留兜底」签字**。
