> **本轮目标**：把阶段一的**终点判据逐条核对一遍**，出**一个结论**，并在通过时**立即冻结基线**。
> **本轮不执行整改**（规范 §一.6 / §一.7）—— 本文件是**计划**，不是执行记录。
> **本轮是整个计划的终点** —— 无论结论是「通过」还是「不通过」，**本计划到此为止**（不自动进入阶段二）。

## ⚠️ 本轮的三条纪律

| # | 纪律 | 为什么 |
|---|---|---|
| **1** | **只核对，不另造标准** —— 判据**原文一个字不许改** | 判据原文在 `docs/PhasedGoal.md` §二（P0 九条）＋ `docs/twoStage.md` §5.6 / §5.7（结论口径 + 冻结 9 项）＋ `docs/PhaseGoal-judge.md` §五/§七/§八/§十一。**改判据 = 自己给自己出考卷再自己判满分** ⇒ 改判据的**当前状态**是 Round 3 的面（已单独一轮），**判据原文**永远是只读 |
| **2** | **「已改」≠「已验证」；「源码级对照」≠「双侧活体对拍」** | 每条判定都要写**证据强度**（L1 源码级 / L2 静态机读 / L3 单侧活体 / L4 双侧活体 / E1 文档成文）⇒ **不许把 L1 说成 L4**。台账里的 ✅ 一律读作「**在该证据强度下一致**」，不是「已闭环」 |
| **3** | **不通过就回 `CT-01`，不许「有条件通过」软着陆** | `twoStage.md` §5.6 的「有条件通过」要求「存在**明确、有限**的例外，且**不破坏核心正确性、安全性、数据完整性**」⇒ **C 类 / D 类**按 §1.1 ⑥ 第 4 条**不计入**⇒ **不构成例外**；但 **A 类**（破坏核心正确性）**不能靠「有限」蒙混过关** ⇒ 不通过就是不通过 |
