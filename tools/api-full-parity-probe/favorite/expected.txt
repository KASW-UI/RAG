# api 整域双侧活体对拍 · 冻结期望值 · favorite 域
# ----------------------------------------------------------------------------
# 本文件是**两侧共用的唯一真源**：Go 侧的值来自真源 favorite-api 的活体实测，
# RAG 侧的值由 run.sh 在每次运行时与本文件逐条比对 ⇒ 不会「各说一半」。
#
# 🔴 冻结的列是 **Go 侧**的完整渲染值 ⇒ 真源的行为一变，探针立刻 exit 1
#    （⇒ 「Go 真源的 api 契约变了」，不是 RAG 回归）。
#
# 渲染格式：status=<HTTP 状态码>|ct=<Content-Type（已做 OWS 归一）>
#           |body=<响应体逐字节（控制字符已转义 \n \r \t）>
#           |biz=<body 里的业务码，取不到为 ->
#           （hkeys=… 只在响应头面那个 OBS 用例里出现）
#
# 五档语义：
#   SAME        —— status + Content-Type + body **全等**
#   SAME_CODE   —— status 全等 **且** 业务码全等（两侧 body 里都取得到码）
#   SAME_BODY   —— status 全等 **且** body 全等（**Content-Type 允许不同**）
#   SAME_STATUS —— **只**要求 status 全等（body 与 Content-Type 允许不同）
#   OBS         —— 两侧**必须不同**（已登记的框架层差异）⇒ 变成一样反而是回归
#   SKIP        —— 显式跳过，理由必须写在本文件里
#
# ⚠️ 为什么有 SAME_STATUS 这一档：Go 的鉴权失败是 **401 + 空 body**
#    （go-zero rest/handler/authhandler.go:106-122 的 unauthorized() 只 WriteHeader(401)）
#    ⇒ Go 侧 body 里**没有业务码** ⇒ 只能断言状态码。
#    两侧 body 的形态差异是**已签字**的有意偏离（DEV-FAV-API-001）⇒ 不算缺陷。
#    Go 侧的精确形态由**冻结值**钉死（status=401|ct=-|body=|biz=-）。
#
# ⚠️ 为什么有 SAME_BODY 这一档：405 的 **Content-Type** 两侧不同 ——
#    Go 是**裸状态码**（go-zero router/patrouter.go:79-82 只 WriteHeader(405)，
#    既无 body 也无 Content-Type）；
#    RAG 侧 `GoStyleRouterErrorResponses.methodNotAllowed` 返回 `ResponseEntity<Void>`，
#    其 javadoc 明写「容器不会补 Content-Type」⇒ **实测被证伪**：
#    Spring 仍会选出一个 MediaType 并写进响应头 ⇒ RAG 多一项 Content-Type。
#    ⇒ 这是**新发现的跨域漂移**，落点在 **service/common** ⇒ 本域**只登记不修**，
#      收口在 `global`（见 docs/DRIFT/favorite/rpc.md §22.4）。
#    ⇒ 405 的 **status 与 body 两侧全等** ⇒ 用这一档把「Content-Type 之外」都纳入比较。
#
# ⚠️ OBS 那一条（h01）：Go 的响应**多一个 W3C `traceparent` 响应头**
#    （go-zero 的 otelhttp 注入 ⇒ 响应回显活动 trace context）；
#    RAG 侧没有 ⇒ **框架/可观测层**差异 ⇒ 单独量化，不混进业务用例。
#
# 🔴🔴 **2026-10-30 活体对拍轮订正 —— 这段说明已经陈旧，档位已改**：
#    「RAG 侧没有 `traceparent`」**不再是事实** ⇒ 根因是**共享层 T-8 已于
#    2026-10-25 第十九轮落地**（`service/common` 新增 `GoStyleTraceparentFilter`
#    ⇒ 10 个 api 全生效）⇒ **两侧现在都有 `traceparent`**。
#    ⇒ 实测（2026-10-30 03:22 `bash tools/api-full-parity-probe/favorite/run.sh`）
#       探针报「**OBS 段期望两侧不同，但变成一样了 ⇒ 请重评台账**」⇒ **活体证据**
#       证明该差异**已闭合**。
#    ⇒ 档位由 `OBS`（要求两侧**必须不同**）改为 `SAME`（要求**全等**）——
#       **不改成 SAME 就等于把这个已闭合的差异继续钉成「必须存在」**
#       ⇒ 那会让任何「RAG 侧少发 traceparent」的回归**静默通过**。
#    ⇒ 改档后本用例从「量化差异」变成「**守住闭合态**」：RAG 侧一旦不再发
#       `traceparent` ⇒ 本用例立刻转红。
#    ⇒ 台账侧对应订正：`docs/DRIFT/favorite/rpc.md`（跨域收口项「Go 多一个
#       `traceparent`」）/ `docs/DRIFT/favorite/api.md`（1 条 OBS 的描述）。
#    ⇒ ⚠️ 证据边界：`frozen` 列仍是 **Go 侧**的值且**未变**（Go 侧一直有
#       `traceparent`）⇒ 本次改的是**比较档位**，不是**冻结值**。
#
# ⚠️ 用例顺序 = 副作用顺序：写入类用例（w01/w02/w03）在只读用例之后，
#    最后 z01 验证「写入确实生效」⇒ 顺序本身就是被冻结的契约的一部分。
