## ⚠️ 本轮的两条纪律

1. 🔴 **本轮不改判据，只改判据的「当前状态」。**
   规范 §0.1 第 3 条：**「绝对不得自行改变的内容 = 阶段一权威判定标准、准入条件、通过阈值、组件与 lane 的权威归属、跨组件不变量、业务行为要求，以及阶段一与阶段二之间的范围边界」**。
   ⇒ 本轮**只允许**改「结论 / 状态 / 证据 / 日期」；**判据原文一个字不许改**。
   ⇒ ⚠️ **不得**为了让矩阵变绿而改判据；**不得**把新发现的问题降级成「已定级不计入」。

2. 🔴 **本轮是唯一能改共享面的一轮。**
   `docs/PhaseGoal-judge.md` · `docs/PhaseGoal/**`（机器生成）· `docs/Stage1/**` · `docs/DRIFT/_cross/**` · `docs/DRIFT/global/**` · `AGENTS.md` · 三个 `_INDEX.md` · `_MANIFEST.json` · 根级文件 ⇒ **全部归合并收口执行者**。
