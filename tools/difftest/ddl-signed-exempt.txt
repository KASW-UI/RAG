# 已签字的**表级** DDL 偏离豁免清单（check-ddl-static.py 用）
#
# 格式（**制表符**分隔，4 列）：
#     <域>\t<table>\t<签字条目号>\t<一句话理由>
#
# ⚠️ **为什么需要这份清单**（2026-10-30 用户拍板）：
#   `check-ddl-static.py` 遇到「两侧列集合不一致」会**硬中止**（EXIT=2），
#   因为它分不清「表名映射写错 / 某一侧没初始化 / 真漂移」三种可能。
#   ⇒ 对**已签字**的表级偏离（如 comment 域的 `report_record`），
#     这个中止会把**其余所有表**的对照一起吃掉
#   ⇒ comment 域因此**默认口径 EXIT=2** ⇒ 连类型/可空/DEFAULT 都比不了
#   ⇒ 那 8 处 DEFAULT 真差**不可机器复算**（台账只能写「人工闭合」）
#   ⇒ **权威数「22 处 DEFAULT 残留」无法用一条命令复现**。
#   ⇒ 本清单让工具**跳过已签字的那张表、继续比其余表**。
#
# ⚠️ **豁免边界（三条，越界即失效）**：
#   ① **只豁免「这张表」**，不豁免该表以外的任何东西；
#   ② **不豁免**索引 / DEFAULT / CHECK 层面的差异
#      —— 那些走 `--allow-idx` / `--allow-default`（**粒度是列/索引名，不是表**）；
#   ③ **只在本表列出的域生效**；未列入本文件的表 ⇒ 仍按原样「中止 + EXIT=2」。
#
# ⚠️ **「跳过」≠「已核对」**：输出会单列 **「已签字豁免 · 未核对」**
#   ⇒ 这张表**今后新增的真差异，本工具抓不到** ⇒ 需人工巡检
#   ⇒ 因此本文件**每加一行，都必须写清签字条目号**（可回溯到 Intentional_Deviations）。
#
# ⚠️ **为什么是显式数据文件、而不是去解析 `docs/Intentional_Deviations/**.md`**：
#   散文 markdown 的表格/标题形态会随人手编辑漂移 ⇒ 解析器一脆，
#   要么**误豁免**（把真差异洗成绿），要么**误报**（把已签字的报成新漂移）
#   ⇒ **弱兜底判据会把真缺陷洗成「0」** ⇒ 显式清单更稳、也更好审计。
