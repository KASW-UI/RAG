## 本轮的动作

1. **分流**：新欠账逐条定级（`twoStage.md` §10 的 P0–P3 × A/B/C/D）⇒
   - **A 类**（阻阶段一）⇒ **本轮必须修完**
   - **B 类**（竞争力）⇒ 能量就修，不能量就登记
   - **C 类**（阶段二）⇒ **登记，不修**（并入交付物 5 的暂缓项清单）
2. **派工**：按域派回四条 lane（写权同 `_INDEX.md` §三）⇒ 域侧能自修的域侧修 ⇒ 共享层转 G4
3. **复判**：改基线 → 重跑生成器 → 重跑 R4 的验收命令 ⇒ 结论仍为「通过」
4. **更新状态**：`_INDEX.md` §五 状态表 + 本文件写「触发原因 / 实际内容 / 复判结论」
