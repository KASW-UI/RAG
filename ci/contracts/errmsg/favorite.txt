# 【这是什么】
#   Java 侧favorite 域错误码契约的**机器可读基准**。
#   CI 用 `ci/scripts/check-errmsg-contract.sh` 跑 **Java 半边探针**
#   （`tools/errmsg-probe/favorite/java/Probe.java`）并与本文件的 dump 段**逐字节**比对。
#
# 【权威性来源 = Go 真源（只读 · 冻结）】
#   Go 真源：Sea-RideTheWind_golang/service/favorite/common/errmsg.go
#     · const 块 :8-41 · codeMsg 表 :43-75 · GetErrMsg :91-97 · bizCodeFromMessage :99-102 · GRPCError :104-106 · BizCodeFromError :108-
#   Java 被测：service/favorite/favorite-common/src/main/java/com/rag/favorite/favorite/common/errmsg/{FavoriteErrorCode,FavoriteErrorMessages,FavoriteGrpcError}.java
#
# 【提取方式（离线 · 一次性 · 可复算）】
#   2026-10-31 用 `tools/errmsg-probe/favorite/run-parity.sh` 跑**双侧对拍**：
#     · Go 半边：把真源 `errmsg.go` 复制进临时模块、与真源**同包**编译后跑
#       （复制件与真源比 sha256，不一致即 exit 2 ⇒ 验的确实是真源）；
#     · Java 半边：`javac` 编译探针 → 跑**真实编译产物**（`<域>-common` 的
#       `target/classes`）⇒ 探针自己**不持有任何码值/文案常量**（否则是「拿 RAG 的值验 RAG 的值」）。
#   本文件 = **Java 侧 dump**（Java 侧应当满足的契约）。
#   ⇒ Go 仓**不需要**在线、Go 工具链**不需要**进 CI 镜像。
#
# 【裁定依据】
#     · Go↔Java 双侧 dump 有 **2 条差异**，全部落在 `OBS` 段（两侧**必然不同**的已批准差异）。
#     · 裁定依据：`docs/Intentional_Deviations/favorite/common.md`（`DEV-FAV-COMMON-001` / `DEV-FAV-COMMON-002`，均已签字）
#     · + `docs/DRIFT/favorite/vs-common.md` + `tools/errmsg-probe/favorite/README.md` 的 OBS 段说明。
#
# 【本域已批准差异清单】（Go 侧 vs Java 侧 · **逐条** · 共 2 条）
#   ⑴ OBS|obs_custom_grpcstatus
#        Go   : 5007
#        Java : 1015
#        裁定 : 已签字 · DEV-FAV-COMMON-001 / 002 + 已登记 —— Go 的 `status.FromError` 认「顶层实现 `GRPCStatus()`」⇒ 文案反查命中 ⇒ 5007； Java 的 `FavoriteGrpcError#extractStatus` 只认 `StatusException` / `StatusRuntimeException` 两个具体类 ⇒ 认不出 ⇒ 1015。favorite 域实际 error 全部来自 gRPC stub ⇒ 不可达。 出处：`tools/errmsg-probe/favorite/README.md` OBS 段 + `docs/Intentional_Deviations/favorite/common.md`。
#   ⑴ OBS|obs_ok_status
#        Go   : 200
#        Java : 5001
#        裁定 : 已签字 · DEV-FAV-COMMON-001 / 002 + 已登记 —— Go 的 `status.Error(codes.OK, msg)` **返回 nil** ⇒ `BizCodeFromError(nil)` = 200； Java 的 `grpcError(OK, …)` 返回一个 `code=OK` 的 `StatusException`（非 nil）⇒ 走反查/兜底 ⇒ 5001。 favorite 域 56 个 `GRPCError` 调用点**没有一个**传 `codes.OK` ⇒ 不可达。 出处：`tools/errmsg-probe/favorite/README.md` OBS 段 + `docs/Intentional_Deviations/favorite/common.md`。
